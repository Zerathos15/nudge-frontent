# NUDGE

## Purpose
Personal learning scheduler and mastery platform.

## Current state
Frontend/UI prototype with existing interactions and mock data.

## Important
The frontend was originally designed in v0/Vercel and should be preserved. This package keeps the existing framework, source tree, configuration, assets, interactions, and mock data intact so development can continue in Google AI Studio.

## Development

Install dependencies with pnpm:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Build the project:

```bash
pnpm build
```
